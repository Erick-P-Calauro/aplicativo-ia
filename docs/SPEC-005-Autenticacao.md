# SPEC-005 : Autenticação

Essa especificação trata do processo de autenticação do usuário root do sistema.

## Requisitos Funcionais 

RF-11 : O sistema deve proteger as rotas marcadas com auth required.

RF-12 : O sistema deve permitir a autenticação do usuário root do sistema.

## Requisitos Não Funcionais

RNF-04 : O processo de autenticação deve seguir o esquema de token de acesso JSON.

RNF-05 : Deve haver um único usuário root no sistema.
