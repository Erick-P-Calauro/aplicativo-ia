# SPEC-003 : Interface Visual

Essa especificação trata da interface disponibilizada ao usuário para utilizaçaõ do sistema.

## Requisitos Funcionais 

RF-09 : O sistema deve disponibilizar uma interface visual para cadastro dos usuários.

RF-10 : O sistema deve disponibilizar uma interface visual para reconhecimento facial do usuário por meio de fotos.

## Fluxos esperados : 

### Cadastro de Usuário

Páginal Inicial -> Página de Cadastro -> Preenchimento de Formulário e Anexação de Foto -> Cadastro Efetuado.

### Listagem de Usuário

Página Inicial -> Página de Admin -> Root User + Root Password -> Página de Listagem dos Usuários

### Deleção de Usuário

Página Inicial -> Página de Admin -> Root User + Root Password -> Página de Listagem dos Usuários -> Deleção de Usuário

### Reconhecimento Facial

Página Inicial -> Página de Reconhecimento Facial -> Foto -> Detecção de Faces -> Reconhecimento de Face.
